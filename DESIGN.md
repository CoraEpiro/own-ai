# Design System: Own AI

> Generated by `taste-design` skill. This is the single source of truth for all UI work.
> Implement with React 18 + Tailwind CSS 3. No shadcn. No Inter. No neon.

---

## 1. Visual Theme & Atmosphere

**Density:** 6 — Daily App Balanced. Enough breathing room to feel premium; enough information density to feel like a real tool.

**Variance:** 7 — Offset Asymmetric. Hero sections are split-screen, never centered. Feature rows use zig-zag and asymmetric grids, never 3 equal cards.

**Motion:** 5 — Fluid CSS. Spring-physics for interactive elements. Staggered cascade reveals. Perpetual micro-loops on live-state indicators. No cinematic excess in a productivity tool.

**Atmosphere:** A well-lit studio where serious work happens. The kind of interface a graduate student would have open at 2 AM without it feeling hostile. Clinical precision without coldness — think Vercel's dashboard crossed with Linear's restraint. Dark by default, light mode equally considered. The brand gradient (`Violet → Indigo`) appears only as a spark: icon fills, active states, a single CTA. Never as a background.

## 3. Typography Rules

### Font Stack

```css
/* Replace Inter immediately. New stack: */
--font-body:    'Geist', 'Outfit', system-ui, sans-serif;
--font-display: 'Cabinet Grotesk', 'Geist', sans-serif;  /* Headlines, hero text */
--font-mono:    'Geist Mono', 'JetBrains Mono', monospace;
```

**Loading:** Via `fontsource` packages (no Google Fonts CDN latency). Install:
```bash
npm install @fontsource/geist @fontsource/geist-mono @fontsource-variable/cabinet-grotesk
```

### Scale & Hierarchy

| Role | Size | Weight | Tracking | Notes |
|---|---|---|---|---|
| Hero headline | `clamp(3rem, 6vw, 5.5rem)` | 800 | `-0.05em` | Cabinet Grotesk, track-tight |
| Section headline | `clamp(1.75rem, 3vw, 2.5rem)` | 700 | `-0.03em` | Cabinet Grotesk |
| Card title | `1.125rem` | 600 | `-0.01em` | Geist |
| Body copy | `1rem` | 400 | `0` | Geist, max `65ch` line length |
| Caption / meta | `0.75rem` | 500 | `+0.08em` uppercase | Geist, all-caps metadata |
| Code / numbers | `0.875rem` | 400–500 | `0` | Geist Mono |

**Anti-patterns:**
- Never use `text-7xl` without `tracking-tight`  
- Never use `font-bold` on body text  
- Never uppercase entire paragraphs — only labels and metadata  
- Dashboard UIs: Sans-serif pairing only (`Geist` + `Geist Mono`)

## 4. Component Stylings

### Buttons

**Primary CTA**
- Background: `var(--brand-gradient)` — `linear-gradient(135deg, #6366F1, #8B5CF6)`
- Shape: `border-radius: 999px` (pill) — no squared buttons
- Padding: `0.75rem 1.75rem`
- Text: `0.875rem`, `font-weight: 600`, `color: white`
- Active state: `-1px translateY` — tactile push. No scale transforms
- Focus: `outline: 2px solid #6366F1`, `outline-offset: 3px`
- Hover: `opacity: 0.9` + slight brightness lift — no outer glow, no shadow explosion
- **BANNED:** `box-shadow` with colored glow on hover

**Secondary / Ghost**
- Background: `transparent`
- Border: `1px solid var(--border-default)`
- Text: `var(--text-secondary)`
- Hover: `background: var(--surface-2)`, `color: var(--text-primary)`
- Same pill shape as primary

**Destructive**
- Border: `1px solid rgba(239,68,68,0.3)`
- Text: `#EF4444`
- Background: `rgba(239,68,68,0.06)` on hover

### Cards & Containers

- Corner radius: `1.25rem` (`20px`) — "Generously rounded, not bubbly"
- Background light: `#FFFFFF` with `1px solid rgba(0,0,0,0.08)` border
- Background dark: `rgba(28,28,31,0.9)` with `1px solid rgba(255,255,255,0.08)` border
- Shadow light: `0 1px 3px rgba(0,0,0,0.06), 0 4px 16px rgba(0,0,0,0.04)` — whisper-soft
- Shadow dark: `0 4px 16px rgba(0,0,0,0.4), 0 0 0 1px rgba(255,255,255,0.06)` — tinted to bg
- **Backdrop blur:** Only on overlaid panels (sidebar, topbar, modals). Never on static cards
- **Use cards only when elevation communicates hierarchy.** For high-density list rows, use `border-top` dividers with `1px solid var(--border-subtle)` instead

### Navigation Sidebar

- Width: `17rem` fixed
- Background: Frosted glass — `rgba(250,250,250,0.88)` light / `rgba(17,17,19,0.88)` dark
- `backdrop-filter: blur(20px)` — sidebar only
- Active item: `background: rgba(99,102,241,0.10)`, `border-left: 2px solid #6366F1` (inset indicator), text `var(--text-primary)`
- Inactive item: No background, text `var(--text-secondary)`, hover state `rgba(99,102,241,0.06)`
- Section labels: `0.6875rem`, `font-weight: 600`, `letter-spacing: 0.14em`, all-caps, `var(--text-muted)`
- Transition: `background 0.18s ease, color 0.15s ease`

### Inputs & Forms

- Background: `var(--bg-base)` — same as page, no inset effect
- Border: `1px solid var(--border-default)`, `border-radius: 0.75rem`
- Focus: Border becomes `#6366F1`, ring: `0 0 0 3px rgba(99,102,241,0.15)`
- Label: **Above** the input, never floating. `0.875rem`, `font-weight: 500`
- Error: Text below input, `#EF4444`, `0.75rem`
- Placeholder: `var(--text-muted)`
- Height: `2.75rem` (`44px` minimum for touch targets)

### Chat Interface

- User message bubble: Right-aligned, `border-radius: 1.25rem 1.25rem 0.25rem 1.25rem`, background `var(--surface-2)` light / `rgba(99,102,241,0.12)` dark
- AI message: No bubble — rendered inline with avatar to the left. Full-width prose
- Avatar: `2.25rem` circle, colored by provider accent
- Message spacing: `1.25rem` gap between exchanges
- Input bar: Sticky bottom, `border-top: 1px solid var(--border-subtle)`, same frosted glass as topbar

### Loading & Skeleton States

- **Skeletal shimmer** matching exact layout dimensions of the content it replaces
- Shimmer gradient: `linear-gradient(90deg, var(--surface-2) 25%, var(--surface-3) 50%, var(--surface-2) 75%)`
- `background-size: 200% 100%`, animated via `@keyframes shimmer`
- **BANNED:** Circular spinners anywhere except inline small loaders (< 16px)

### Empty States

- Composed illustration or icon cluster (Lucide icons arranged)
- Headline: What this section is for
- Subtext: How to populate it (action-oriented, not "No data found")
- Optional single CTA

## 5. Layout Principles

### Grid Architecture

- **CSS Grid over Flexbox math** — never `calc()` percentage hacks
- Container: `max-width: 1400px`, `margin: 0 auto`, `padding: 0 clamp(1rem, 4vw, 2rem)`
- Inner content: `max-width: 1200px` for reading/form content
- Section vertical gaps: `clamp(4rem, 8vw, 7rem)`

### Hero Section (Landing)

**BANNED:** Centered single-column hero  
**Required:** Split-screen asymmetric — left text column, right live mockup panel

```
[text content — 52%] | [product demo panel — 48%]
```

- Left: Left-aligned, not centered. Eyebrow → Headline → Subtext → CTA → Social proof
- Right: A living product mockup (dark-glass panel) showing a real chat interaction
- Eyebrow: Small pill badge — `border-radius: 999px`, `border: 1px solid rgba(99,102,241,0.25)`, `background: rgba(99,102,241,0.08)`, `0.6875rem` uppercase tracking
- Headline: 2–3 lines maximum. Weight 800. Cabinet Grotesk. Tracking `-0.05em`
- Single primary CTA. No "Learn more" secondary links in the hero.

### Feature Grid (Landing)

**BANNED:** 3 equal horizontal cards  
**Required:** 2-column zig-zag alternating layout for primary features, or Bento-style asymmetric grid

Bento grid pattern:
```
[Large feature — 60%] [Tall feature — 40%]
[Medium — 33%] [Medium — 33%] [Medium — 33%]  ← only for minor features
```

### App Shell

- Sidebar: Fixed left, `17rem`, always visible on `lg+`, sheet/drawer on mobile
- Topbar: Sticky top, `3.5rem` height, `backdrop-filter: blur(18px)`
- Content: `padding: 1.5rem 2rem` on desktop, `1rem` on mobile
- Page header (title + description) inside content area, not topbar

### Responsive Rules

- **< 768px:** All multi-column → single column. No exceptions.
- **Sidebar:** Collapses to bottom navigation or drawer on mobile (`< 1024px`)
- **Hero split:** Stacks vertically on mobile — text first, mockup second
- **Typography:** All headlines via `clamp()`. Body minimum `1rem`
- **Touch targets:** `44px` minimum — all buttons, links, nav items
- **Section gaps:** `clamp(3rem, 6vw, 5rem)` on mobile
- **`min-h-[100dvh]`** — never `h-screen` (iOS Safari jump bug)

## 6. Motion & Interaction

### Spring Physics Default

```css
/* For JS-driven animation (Framer Motion or CSS springs) */
transition: { type: 'spring', stiffness: 120, damping: 22 }

/* For CSS transitions */
transition: transform 0.22s cubic-bezier(0.34, 1.56, 0.64, 1);
```

### Perpetual Micro-Interactions

Active live-state indicators (e.g., "Streaming...", "Voice active"):
```css
@keyframes pulse-dot {
  0%, 100% { opacity: 1; transform: scale(1); }
  50%       { opacity: 0.5; transform: scale(0.85); }
}
.live-dot { animation: pulse-dot 1.8s ease-in-out infinite; }
```

Skeleton shimmer:
```css
@keyframes shimmer {
  from { background-position: 200% 0; }
  to   { background-position: -200% 0; }
}
```

### Staggered Cascade Reveals

For lists, card grids, and feature rows:
```css
.stagger-child:nth-child(1) { animation-delay: 0ms; }
.stagger-child:nth-child(2) { animation-delay: 60ms; }
.stagger-child:nth-child(3) { animation-delay: 120ms; }
/* Max 6 items staggered. Beyond that, instant mount. */
```

### Performance Rules

- Animate exclusively via `transform` and `opacity`
- **NEVER** animate `top`, `left`, `width`, `height`, `background-color` directly
- Grain/noise textures: `position: fixed` pseudo-elements only, `pointer-events: none`
- Background orbs: CSS-only, no JS. `will-change: transform` on animated elements only

## 9. Anti-Patterns (Banned for Own AI)

### Typography
- `Inter` font — **banned**. Replace with `Geist`
- `Sora` — banned. Replace with `Cabinet Grotesk` for display
- Generic system fonts for body text
- Serif fonts anywhere in the app

### Color
- Pure `#000000` — use `#09090B` or `#18181B`
- Neon outer glows: `box-shadow: 0 0 20px #6366F1` on hover — banned
- Oversaturated accent fills (saturation > 80%)
- Three-color brand gradient as background fill — gradient is a spark only
- Warm gray mixed with cool gray (`stone` + `zinc`) — pick one family

### Layout
- Centered hero section on the landing page — banned
- 3 equal-width cards in a horizontal row — banned
- `h-screen` — use `min-h-[100dvh]`
- `calc()` percentage width hacks — use CSS Grid `fr` units

### Components
- `alert()`, `confirm()`, `prompt()` — use toast notifications
- Circular spinners > 16px — use skeletal loaders
- Floating labels on inputs — label above always
- Tooltips without accessible `aria-label`

### Content & Copy
- "Elevate your workflow", "Seamless experience", "Unleash potential", "Next-gen" — banned
- "Scroll to explore", bouncing chevrons, scroll progress bars — banned
- Fake statistics: "99.98% uptime", "124ms avg response" — never fabricate metrics
- Generic placeholder names ("John Doe", "Acme Corp")
- `LABEL // YEAR` formatting conventions
- Broken Unsplash image URLs — use `picsum.photos` or SVG avatars

### Motion
- `transition: all` — always specify the property
- Animating `top`, `left`, `width`, `height`
- `linear` easing — always use `ease-in-out`, `cubic-bezier`, or spring
