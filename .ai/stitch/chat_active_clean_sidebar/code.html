Can you help me calculate the efficiency of a Carnot engine operating between 500K and 300K? Also, write a small Python snippet to automate this for different temperatures.

The efficiency (\(\eta\)) of a Carnot engine is determined solely by the temperatures of the hot (\(T_H\)) and cold (\(T_C\)) reservoirs. The formula is:

η = 1 - (T_C / T_H)

For your specific values:
\(T_H = 500K\) and \(T_C = 300K\)
\(\eta = 1 - (300 / 500) = 1 - 0.6 = 0.4\) (or 40%).

Here is a Python function to calculate this efficiently for any set of temperatures:

def carnot_efficiency(t_hot, t_cold):
    """Returns efficiency as a decimal."""
    if t_hot <= 0:
        return 0
    return 1 - (t_cold / t_hot)

print(f"Efficiency: {carnot_efficiency(500, 300):.2%}")
